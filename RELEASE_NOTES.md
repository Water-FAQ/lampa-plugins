# Shikimori by WaterFAQ 1.0.0

Первый стабильный выпуск плагина каталога Shikimori для Lampa.

- Русский интерфейс, быстрые разделы и фильтры с отображением выбранных значений.
- Карточки со статусами и рейтингами, управление пультом.
- Поиск карточки TMDB с индикатором этапов, повторной попыткой и отменой.
- Рейтинг Shikimori в полной карточке Lampa.
- Студии связанных сезонов, фоновая загрузка и кэш.

Файл подключения: `Shikimori.js` в корне GitHub Pages. Постоянный адрес приведён в README и должен быть проверен после публикации.

Это описание подготовлено для релиза с тегом `v1.0.0`; сам релиз ещё не создан.
