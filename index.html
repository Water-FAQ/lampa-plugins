Рейтинг

Нужная оценка на постере

По умолчанию — IMDb. Если оценки нет, плагин выбирает Кинопоиск, затем TMDB. Приоритет можно изменить в настройках.

  • Загрузка оценок в фоне без открытия карточек.
  • Цвета в списках и внутри карточки, включая Shiki.
  • Две цветовые шкалы и кэш на сутки.

Shikimori

Аниме под рукой

Каталог Shikimori в боковом меню Lampa: популярное, текущий сезон, анонсы, фильмы и лучшие по рейтингу.

  • Подборки и фильтры по жанру, типу, сезону и статусу.
  • Открытие найденной карточки TMDB в Lampa.

Старый вид истории просмотров

Знакомый экран истории

Возвращает вид истории, который использовался до Lampa 3.4.0. Сохранение просмотров и синхронизация CUB остаются штатными.

После перезапуска откройте «Историю» заново. В старых версиях Lampa, где новый экран отсутствует, изменений не будет.

Как установить

  1. Выберите плагин
    Скопируйте его адрес в каталоге выше.
  2. Откройте расширения
    Настройки → Расширения. В некоторых сборках — «Плагины».
  3. Добавьте адрес
    Выберите «Добавить плагин», вставьте ссылку и подтвердите.
  4. Перезапустите Lampa
    Каждый выбранный плагин добавляется отдельно.

Адреса подключения постоянные. Для обновления менять ссылку не нужно. Отключите прежние копии того же плагина с других адресов.

Рейтинг: настройте под себя

Выбор источника

Настройки → Рейтинг → Приоритет. IMDb: IMDb → Кинопоиск → TMDB. Кинопоиск: Кинопоиск → IMDb → TMDB. TMDB: TMDB → IMDb → Кинопоиск.

Цвета и кэш

Включайте цвета отдельно для списков и полной карточки. Подробная шкала содержит четыре цвета, простая — три. Сведения хранятся сутки; очистка кэша доступна здесь же.

Оценки до открытия карточки

Плагин загружает данные для видимых и ближайших постеров из источника Lampa. До получения ответа может показываться TMDB. Доступность других оценок зависит от ответа сервиса.

Вместе с Shikimori

Штатные оценки внутри карточки сохраняются. «Рейтинг» окрашивает и добавленную оценку Shiki. Отдельные плагины получения IMDb и Кинопоиска не требуются.

0 < оценка < 55 ≤ оценка < 77 ≤ оценка < 88 ≤ оценка ≤ 10

Если что-то не работает

Обновление не появилось

Полностью перезапустите Lampa или обновите плагины средствами своей сборки. Адрес подключения остаётся тем же.

Данные выглядят устаревшими

Для рейтингов: Настройки → Рейтинг → Очистить кэш. Для Shikimori: Фильтры → Очистить кэш сопоставлений. Параллельные плагины, меняющие те же оценки или цвета, могут мешать отображению.

Для работы нужен доступ к соответствующим сервисам. Воспроизведение зависит от вашей сборки Lampa и установленных источников просмотра. Сообщить о проблеме.
