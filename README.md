# Shikimori by WaterFAQ

Плагин каталога аниме Shikimori для Lampa. Версия 1.0.0.

## Возможности

- Каталог с русскими названиями, постерами, рейтингами, типом, сезоном и статусом аниме.
- Главная с сортировкой по популярности.
- Быстрые разделы: популярное, сейчас выходит, текущий сезон, анонсы, лучшие по рейтингу, фильмы и случайная подборка.
- Фильтры по типу, статусу, жанру, сезону и сортировке; строка выбранных фильтров и сброс.
- Открытие соответствующей карточки TMDB, выбор при нескольких результатах и одна автоматическая повторная попытка при неудаче поиска.
- Индикатор этапов поиска и отмена открытия кнопкой «Назад».
- Рейтинг Shikimori в полной карточке, после остальных рейтингов и перед возрастным ограничением.
- Студии связанных сезонов сериалов, без повторов. Обход включает только связи Prequel/Sequel между TV и ONA; фильмы, спецвыпуски и побочные истории исключены.
- Кэш на 30 дней, до 300 записей на категорию, с ручной очисткой в меню фильтров.
- Управление пультом: вверх из первого ряда — на «Главная», вправо с крайней карточки — фильтры; «Назад» возвращает на предыдущую страницу.

Код отображения команд озвучки и субтитров сохранён, но выключен.

## Подключение

После публикации репозитория `Water-FAQ/lampa-plugins` через GitHub Pages постоянный адрес будет таким:

```text
https://water-faq.github.io/lampa-plugins/Shikimori.js
```

Это планируемый адрес: он начнёт работать только после создания репозитория и включения Pages.

Добавьте адрес в разделе расширений/плагинов Lampa и перезапустите приложение. Названия пунктов настройки могут отличаться между сборками Lampa.

Если плагин ранее подключён по другому адресу, отключите старую копию перед подключением новой.

## Публикация на GitHub

1. Создайте публичный репозиторий `lampa-plugins` после урегулирования условий распространения исходного кода (см. THIRD_PARTY_NOTICES.md).
2. Загрузите файлы из этого пакета в корень ветки `main`, включая `.nojekyll`.
3. В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/(root)` и сохраните.
4. Дождитесь публикации и проверьте адрес `Shikimori.js`.
5. Создайте релиз с тегом `v1.0.0`. Описание подготовлено в RELEASE_NOTES.md.

## Обновления

Проверенные обновления заменяют файл `Shikimori.js` по тому же пути. Не меняйте имя репозитория, имя файла или регистр букв: от этого зависит постоянный адрес подключения.

Для исправлений используйте версии 1.0.1, 1.0.2; для новых возможностей — 1.1.0. Изменяйте номер в манифесте плагина и добавляйте запись в CHANGELOG.md. Релизы фиксируют проверенные состояния; Lampa загружает файл через Pages. Из-за кэша обновление может потребовать перезапуска приложения.

## Зависимости и ограничения

Требуется доступ к Shikimori API, TMDB и сервису сопоставления идентификаторов `arm.haglund.dev`. Доступность этих сервисов влияет на поиск и дополнительные сведения. Плагин не предоставляет видеопотоки.

Студии связанных сезонов собираются в фоне при первом открытии. Список зависит от связей, заполненных в Shikimori, и сохраняется в кэш. Рейтинг относится к найденной части Shikimori; сбор студий его не меняет.
